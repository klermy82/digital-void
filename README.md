# Digital Void

**[klermy82.github.io/digital-void](https://klermy82.github.io/digital-void/)**

Сайт-терминал компании Digital Void. При входе приветствие на разных языках, и терминал. Команда в терминале открывает нужный сайт, страница при этом не перезагружается.

```
user008@jailbreak : ~$ portfolio
```

## Команды терминала


| Команда                            | Что откроется              |
| ---------------------------------- | -------------------------- |
| `portfolio`                        | портфолио klermy           |
| `freedom`                          | сайт организации «Свобода» |
| `wtf`                              | в разработке               |
| `help` · `ls` · `clear` · `whoami` | служебные                  |


↑↓ — история команд, Tab — дополнение, Esc — сразу в портфолио.

## Прямые ссылки

- `[?portfolio](https://klermy82.github.io/digital-void/?portfolio)` — сразу портфолио
- `[?freedom](https://klermy82.github.io/digital-void/?freedom)` — сразу «Свобода»
- `[?terminal](https://klermy82.github.io/digital-void/?terminal)` — сразу терминал, без приветствия



## Что внутри

**Портфолио klermy:** плагины и датапак для Minecraft (Paper / Spigot 1.21), два Telegram-бота ([@void_butler_bot](https://t.me/void_butler_bot), [@otkormysh_bot](https://t.me/otkormysh_bot)), кумиры и ссылки.

**«Свобода»:** организация, которая ловит мультивселенские аномалии на сервере СП и отправляет их домой через порталы. На сайте досье, персонал, технологии и набор. (Нужен для 6 сезона СП)

## Как устроено

Весь сайт — один файл `index.html`, без сборки и зависимостей. Внутри HTML, CSS и JS, картинки встроены прямо в файл.
